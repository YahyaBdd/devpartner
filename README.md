# DevPartner

Single-page portfolio using the Blue Circuit design and original English, German and Dutch copy.

Run `npm install`, then `npm run dev`. Build with `npm run build`.

- Page: `src/pages/index.astro`
- Layout and components: `src/portfolio/`
- Copy: `src/i18n/`
- Language engine: `src/components/I18nEngine.astro`

The concept gallery, alternate designs, unused legacy components and copy-rewrite artifacts have been removed.
